## The bottleneck in v4

I inspected both supplied contact sheets and sampled the actual MP4 at 5.8, 7.2, and 28.5 seconds. `ffprobe` reports 59.648 seconds, 1920×1080, 30 fps, H.264/AAC. This was a visual inspection, not a full playback or listening review.

The opening premise is strong. The rest repeatedly returns to dark panels, small UI, and explanatory captions. The vertical sheet magnifies the sameness. My diagnosis: the film needs stronger changes of scale, clearer visual hierarchy, and fewer demonstrations. Buying another renderer will not fix those decisions.

There is already more infrastructure than the brief suggests. [device.tsx](/Users/nikita/Projects/agent-notch-release/promo/src/device.tsx) supports animated screen replacement using Blender corner coordinates. [The promo README](/Users/nikita/Projects/agent-notch-release/promo/README.md) documents a shared beat grid, sound cues, and separate vertical layouts. The screen looks dark in the sheet, but an absent compositing capability is not established. Preserve this machinery. Use the app’s existing `--snapshot` capability for authentic pixels rather than expanding the React facsimile.

**Most visually ambitious output I could directly inspect: open-fusion-mcp’s explainer.** I decoded its [published MP4](https://github.com/legionsound/open-fusion-mcp/blob/main/docs/media/open-fusion-mcp-explainer.mp4) into six sampled frames. ## Skills: teach the production process first

Install the maintained [Remotion skills](https://www.remotion.dev/docs/ai/skills) with `npx skills add remotion-dev/skills`. Claude then uses `/remotion-markup`, `/remotion-studio`, and `/remotion-render` to implement, preview, and render scoped shots. This is the highest-return tooling addition because the project already uses Remotion.

[Anthropic’s skills repository](https://github.com/anthropics/skills) is an official foundation, not a verified film-director package. Its [canvas-design](https://github.com/anthropics/skills/blob/main/skills/canvas-design/SKILL.md) is for static artwork; [algorithmic-art](https://github.com/anthropics/skills/blob/main/skills/algorithmic-art/SKILL.md) uses seeded p5.js. Use them for look frames or abstract background studies, not final video orchestration.

The community [motion-design-with-claude-and-codex](https://github.com/LobzyJay/motion-design-with-claude-and-codex) supplies motion, Blender, AE, and critique skills. Installation is copying selected `skills/` folders into project-local `.claude/skills/` after cloning. Its README contains inconsistent repository/setup references; its “official Blender Lab MCP” claim was **UNVERIFIED** against a Blender primary source. Audit instructions before using them.

For reference analysis, read [sub-level’s motion-from-reference skill](https://github.com/sub-level/marketing-videos/blob/main/.claude/skills/motion-from-reference/SKILL.md). A future `git clone https://github.com/sub-level/marketing-videos.git` provides the source; select the relevant skill rather than importing an entire competing doctrine. [skills.sh](https://skills.sh/remotion-dev/skills) and the [MCP Registry](https://registry.modelcontextprotocol.io/docs) help discovery, but listings alone prove neither app control nor rendering quality.

## MCP and paid tools: where they can earn their cost

**Blender: improve the existing hero shot.** The original ahujasid URL now redirects to [mcp-for-blender](https://github.com/ahujasid/mcp-for-blender), a community project, not Blender Foundation software. PyPI **2.1.9**, released 2026-10-06 ([source](https://pypi.org/project/mcp-for-blender/2.1.9/)), documents `claude mcp add blender uvx mcp-for-blender` and `uvx mcp-for-blender install-addon`. Pin the package for production. Claude calls `get_scene_info`, executes `bpy` through `execute_blender_code`, and uses `look` to inspect camera/animation views. Basic local code control adds no paid generation requirement; optional model-generation services cost extra. Blender 5.1 compatibility on this Mac is **UNVERIFIED**.

For repeatable shots, Claude can simply maintain the existing Python scene and run the repo’s Blender CLI. In `promo/blender`, the existing preview command is `SAMPLES=16 SCALE=50 FRAMES=first,mid,last ./render.sh`. Let the notch occupy the frame, put real UI on the glass, and adjust lighting before expensive sequences. An MCP connection is valuable for inspection, not a substitute for camera design.

**Fusion: the most credible paid experiment.** [open-fusion-mcp](https://github.com/legionsound/open-fusion-mcp) documents Apple Silicon, Python 3.12, and Resolve Studio **21.1**. Clone it; in `connector/`, create a venv and install `requirements.txt`; run `bin/fusion-connector doctor` and `config`. Register the printed command, enable local external scripting, then have Claude use `fu_scene_build`, `fu_do`, and `fu_render_frame`. Native graphs remain editable. [Blackmagic lists Studio at **$295**](https://www.blackmagicdesign.com/products/davinciresolve/studio). Buy only if a short camera/type test beats Remotion. Setup and graph complexity are real risks. The broader [Resolve MCP](https://github.com/samuelgursky/davinci-resolve-mcp), **4.10.6**, 2026-10-12 ([metadata](https://registry.npmjs.org/davinci-resolve-mcp)), installs via `npx davinci-resolve-mcp setup`; its free-edition bridge has version-specific limitations, so do not assume current free Resolve supports this workflow.

**After Effects/Premiere: production automation, not instant art direction.** [TheLlamainator’s AE MCP](https://github.com/TheLlamainator/after-effects-mcp) uses `npm install`, `npm run build`, `npm run install-bridge`, then a running `mcp-bridge-auto.jsx` panel and `node /absolute/path/build/index.js` as Claude’s MCP server. Claude controls compositions, properties, shapes, and scripts through ExtendScript. macOS compatibility of this particular setup is **UNVERIFIED** here. [Adobe lists AE at **$22.99/month, annual billed monthly**](https://www.adobe.com/products/aftereffects.html): this is an annual commitment, not a $23 one-month experiment.

[Premiere MCP](https://github.com/AleksKhanevich/premiere-mcp) reports testing with Premiere **26.0** on macOS. Build its `dist/index.js`, run the CEP bridge, and register Node with `PREMIERE_TEMP_DIR=/tmp/premiere-mcp-bridge`. It assembles media and MOGRTs; the README explicitly preserves the need for graphics assets and editorial judgment. Adobe’s same page lists the regular Creative Cloud Pro bundle at **$69.99/month, annual billed monthly**, including Premiere. Neither Adobe route has a high first-day return for this owner’s current stack.

**Figma, Rive, Spline: verified editor control exists.** [Figma’s official setup](https://developers.figma.com/docs/figma-mcp-server/remote-server-installation/) recommends `claude plugin install figma@claude-plugins-official`; use it for two or three look frames and token extraction. Native canvas writes are documented. [Starter is free](https://www.figma.com/pricing/), with access limits to check before relying on intensive MCP use. [Rive’s official desktop MCP](https://rive.app/docs/editor/ai/mcp) uses `claude mcp add --transport http rive http://127.0.0.1:9791/mcp`; Claude can edit keyframes and state machines. [Pricing lists free exports with a splash screen and Cadet at **$9/seat/month**](https://rive.app/pricing). Useful for a reusable animated mark, less useful for this whole film. [Spline v2’s desktop MCP](https://docs.spline.design/generate/spline-mcp-server) auto-registers supported agents and edits cameras/materials/objects; its [updates](https://updates.spline.design/) establish 2026 MCP availability. Paid pricing and exact Rive/Spline desktop build numbers are **UNVERIFIED**; do not buy Spline for a Blender replacement yet.

**Generated media/audio: bounded supporting roles.** [Comfy’s official local MCP](https://github.com/Comfy-Org/comfy-mcp), **0.10.0**, 2026-08-10 ([metadata](https://pypi.org/pypi/comfy-mcp/json)), documents `pip install comfy-mcp "comfy-cli>=1.14.0"` and `comfy install`. Claude submits workflow JSON, monitors jobs, and collects assets. M1 Max video-generation throughput is **UNVERIFIED**. Avoid making a local diffusion setup the critical path.

[fal’s generation MCP](https://fal.ai/learn/tools/how-to-access-flux-3-on-fal) uses `claude mcp add --transport http fal-ai https://mcp.fal.ai/mcp` with an authorization header. Claude can inspect schemas/prices, upload inputs, and submit/check jobs. This differs from fal’s documentation-only MCP. [Kling 2.5 Turbo Pro image-to-video](https://fal.ai/models/fal-ai/kling-video/v2.5-turbo/pro/image-to-video) lists **$0.35/5 seconds**, then **$0.07/additional second**. Ten five-second attempts therefore cost $3.50 before other assets. Use abstract atmosphere only; approve a still before animating. [Replicate’s official MCP](https://mcp.replicate.com/) offers model discovery/execution through its hosted endpoint; costs are model-specific, not a flat MCP subscription.

[ElevenLabs’ official MCP](https://github.com/elevenlabs/elevenlabs-mcp), **0.12.2**, released 2026-08-04, runs via `uvx elevenlabs-mcp` with API credentials or its hosted OAuth server. Claude generates speech/SFX and saves outputs for FFmpeg mixing. [Starter is **$6/month** with commercial licensing](https://elevenlabs.io/pricing), with a temporary first-month offer shown on the research date. This is the clearest small paid purchase: commission a few distinctive tension/release sounds, then mix them against the existing Suno track. No voiceover is required.

## Top 10 recommendations for Agent Notch

Ranked by expected improvement per hour; hours are planning estimates, not measured performance.

1. **Cut to one 25–35-second argument.** Why: v4’s feature tour dilutes “YOU are the bottleneck.” How: Claude revises the existing shot table around unseen wait → notch → approval → resumed work. Cost: $0 added, 1–2 hours. Risk: secondary features need separate clips.
2. **Make three decisive look frames before animation.** Why: composition failures are cheap to catch as stills. How: Claude renders a chaotic opener, giant amber notch close-up, and clean release frame in Remotion. Cost: $0, 1–2 hours. Risk: attractive stills can hide weak transitions.
3. **Use authentic app pixels.** Why: product credibility and UI detail. How: existing Swift snapshots/real recordings; mask and animate presentation layers around them. Cost: $0, 2–4 hours. Risk: fixture data must be clearly illustrative; screen text still needs framing.
4. **Measure a reference’s motion.** Why: “cinematic” is too vague. How: reference-analysis skill plus FFmpeg; record cap-height ratios, holds, acceleration, and outgoing/incoming shapes. Cost: $0, 2–3 hours. Risk: imitation without an Agent Notch-specific idea.
5. **Keep one amber mark alive through transitions.** Why: visual continuity makes the story feel authored. How: Claude carries a shared object from buried prompt to punctuation to notch to green payoff. Cost: $0, 3–5 hours. Risk: technically clever morphs can obscure the actual app.
6. **Turn the Blender shot into product proof.** Why: empty hardware is decoration. How: reuse corner tracking, show active UI, move from laptop scale to notch macro; review draft frames first. Cost: $0 added, 3–6 hours plus rendering. Risk: steep screen angles and reflections impair readability.
7. **Add official Remotion skills and bounded reviews.** Why: fewer API mistakes, faster pixel feedback. How: install selected skills; render each shot and both aspect ratios before assembly. Cost: $0 added, roughly one hour setup. Risk: automated aesthetic scores become the target.
8. **Spend $6 on purposeful SFX if needed.** Why: a stall, silence, approval, and release can create more drama than extra effects. How: ElevenLabs MCP generates a small approved library; Claude edits/mixes against the existing beat grid. Cost: $6 plus 2–3 hours. Risk: excessive clicks make it a tutorial.
9. **Trial one Fusion hero transition.** Why: native depth/camera tooling has inspectable published evidence. How: open-fusion-mcp builds a 4–6-second shot; compare its pixels with the Remotion equivalent. Cost: $295 Studio if absent, 4–8 hours. Risk: setup can consume the entire benefit; stop after the trial.
10. **Judge the delivered film on a phone.** Why: terminal-sized detail collapses at viewing size. How: human reviews final wide and native vertical MP4s, with sound and muted, plus boundary frames; ask whether the wait and approval are understood. Cost: $0, one hour per review round. Risk: contact sheets alone miss timing and audio.

## What NOT to do

Do not migrate frameworks to escape art direction. Do not buy AE, Resolve, Spline, and Rive together. Do not generate product UI with image/video models. Do not make all thirteen themes, usage accounting, questions, plans, and sounds equal-weight scenes. Do not put a long laptop orbit ahead of the permission payoff. Do not equate stars, MCP tool counts, agent self-scores, or “made in an hour” claims with quality. Do not let beat synchronization replace readable holds. Do not call the next film 10/10 until the owner has watched the exported artifact on the intended surface.
